# 🧠 Teenage Mental Health Dashboard (Power BI Project)

## 📌 Project Overview

This project analyzes **teenage mental health trends** using key factors such as **social media usage, screen time, sleep hours, physical activity, and addiction levels**.

The main objective is to identify patterns and relationships that impact mental health and present them through an **interactive Power BI dashboard**.

---

## 🎯 Problem Statement

In today’s digital world, teenagers are highly exposed to **social media and excessive screen time**, which can negatively affect their mental health.

This project aims to answer:

* Does higher screen time affect sleep and mental health?
* How do different social media platforms influence behavior?
* Is there a relationship between physical activity and stress levels?

---

## 🛠️ Tools & Technologies Used

* **Power BI** – Dashboard creation & data visualization
* **Python (Pandas, NumPy)** – Data cleaning & preprocessing
* **Matplotlib & Seaborn** – Data visualization
* **Excel / CSV** – Dataset handling

---

## 📊 Dataset Description

The dataset includes the following features:

* Age
* Gender
* Screen Time
* Sleep Hours
* Physical Activity
* Anxiety Level
* Depression Level
* Social Media Platform Usage
* Social Interaction Level

---

## 📈 Dashboard Features

* 📌 KPI Cards:

  * Total Screen Time
  * Sleeping Hours
  * Physical Activity
  * Addiction Count

* 📊 Platform Analysis:

  * Instagram vs TikTok vs Both usage

* 👥 Gender Analysis:

  * Addiction levels by gender

* 📉 Behavioral Insights:

  * Social interaction vs screen time

---

## 🔍 Key Insights

* Higher screen time is associated with **lower sleep duration**
* Teenagers using multiple platforms show **higher addiction levels**
* Increased physical activity helps reduce **stress and anxiety**
* Social interaction level influences **daily screen usage patterns**
